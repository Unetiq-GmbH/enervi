# Mock Flask request API for AI image manipulation

Debug mode is off unless `FLASK_DEBUG=1`. Set `EXPRESS_FLASK_KEY` to the same value as the API. The mock returns `output_image.png`, a generated placeholder.

## Commands for windows

### Setup Flask for windows

[Flask Installation](https://flask.palletsprojects.com/en/3.0.x/installation/)

```bash
# Install virtual environment
py -3 -m venv .venv

# Activate virtual environment
.venv\Scripts\activate

# Install from requirements.txt
pip install -r requirements.txt

```
